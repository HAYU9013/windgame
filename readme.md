# 《風巡者：天氣之神》

## 專案概述
《風巡者：天氣之神》是一款以臺灣為舞台、強調策略模擬與上帝視角操作的颱風治理遊戲。玩家扮演新任天氣之神，透過 pygame 建構的互動介面調整颱風生成、路徑、風雨強度與社會資源配置，追求民意、災損、水庫蓄水與神力之間的多重平衡。

## 主要文件
- `GDD.md`：完整的遊戲設計文件，涵蓋定位、遊戲循環、系統設計與世界觀。
- `Todo.md`：逐步執行的開發任務清單，協助安排 pygame 實作流程。
- `assets_list.md`：美術與音效素材需求清單，供製作或採購參考。
- `AGENTS.md`：撰寫文件時需遵循的語言與格式規範。

## 環境建置與執行流程（Conda）
以下步驟以 Conda 為基礎，說明如何在開發機建立環境並啟動遊戲原型：

1. 建立 Conda 環境（建議使用 Python 3.11）：

   ```bash
   conda create -n windgame python=3.11
   ```

2. 啟用虛擬環境：

   ```bash
   conda activate windgame
   ```

3. 安裝相依套件（使用 pip 讀取 `requirements.txt`）：

   ```bash
   pip install -r requirements.txt
   ```

4. （可選）執行單元測試，確認模組行為穩定：

   ```bash
   python -m pytest
   ```

5. 啟動遊戲主程式，預設視窗解析度為 1280×720：

   ```bash
   python -m src.main
   ```

6. 若需結束體驗，可於遊戲視窗中按下關閉鈕或使用鍵盤快捷鍵（例如 `Alt + F4`）。

## 技術方向與目標
- 以 pygame 為基礎建立原型，聚焦地圖顯示、颱風控制面板與即時新聞回饋。
- 逐步導入簡化的氣象模擬邏輯，讓玩家操作帶來明確且可視化的結果。
- 透過分章節的關卡架構與事件系統，展現臺灣在多變氣候下的社會樣貌。

## 當前原型亮點
- 事件系統資料化管理梅雨、高壓、秋颱與選舉敏感期等情境，動態調整降雨、風勢與神力成本。
- 控制面板同步顯示年份、月份、季節與事件摘要，協助玩家掌握局勢與資源變化。
- 新聞跑馬燈可即時更新訊息快照，確保最新決策在畫面底部快速播報。
- 「島嶼脈動」焦點區塊彙整水情、民意與季節態勢，提供更豐富的敘事回饋與決策依據。
